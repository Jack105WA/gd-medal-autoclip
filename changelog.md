# Changelog

## v1.1.0
- Removed Medal Developer Portal public-key and event-ID requirements.
- Replaced API event requests with Medal's regular clip hotkey.
- Added configurable Medal hotkey (F8 by default).
- Added configurable capture delay.
- Removed clip duration and title settings that cannot be controlled through the hotkey.

## v1.0.0
- Initial Windows Geode mod implementation.
- New-best and level-completion event detection.
- Medal local API integration.
- Configurable event IDs, clip naming, and clip timing.
- GitHub Actions Windows x64 package workflow.
